# 🌊 Seascape Whispering Wicks

A modern, responsive website built to showcase **Seascape Whispering Wicks**, a handmade candle brand specializing in 100% pure beeswax and coconut oil candles inspired by the beauty of the ocean.

This project is being developed as a **Minimum Viable Product (MVP)** with the goal of establishing a clean online presence for the brand before expanding into a full-featured e-commerce experience.

---

## 📖 Overview

Seascape Whispering Wicks combines coastal aesthetics with handcrafted, eco-friendly candles made from natural ingredients and scented with premium essential oils.

The MVP focuses on introducing the brand, displaying the candle collection, sharing the story behind the maker, and providing a way for customers to get in touch.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/amber-goding/seascape-whispering-wicks.git
```

### Navigate into the project

```bash
cd seascape-whispering-wicks
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The application will then be available in your browser at the local development URL displayed by Vite.

## 📱 MVP Navigation

The website currently contains four primary sections:

* **Home** – Introduction to Seascape Whispering Wicks
* **Candles** – Scrolls to the featured candle collection
* **About** – Learn about the candle maker
* **Contact** – Contact form for customer inquiries

This MVP intentionally keeps navigation simple while establishing the brand identity.
